# מתי המתי״א — MATI

יישומון רפלקטיבי־מערכתי למדריכות חינוכיות, בנוי ב־Next.js App Router.

## מה יש בגרסת הפיילוט

- זיהוי אוטומטי של שלב השנה: תכנון / הערכה מעצבת / הערכה מסכמת.
- Guard rails למעבר בין שלבים.
- תוכנית עבודה עם סף מידע מינימלי.
- מסלול הערכה מעצבת מלא או ממוקד.
- מראה מקצועית לפי 5 ממדי הפיקוח.
- 3 שאלות מסכמות ומחוון לשנה הבאה.
- שמירה מקומית בדפדפן בלבד (`localStorage`).

## פיתוח

```bash
npm install
npm run dev
```

## פרטיות

בגרסה זו אין backend ואין שליחת מידע לשרת. נתוני המשתמשת נשמרים בדפדפן המקומי בלבד.
