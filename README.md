# מתי המתי״א — MATI

**מתי המתי״א** הוא יישומון אימון רפלקטיבי־מערכתי למדריכות חינוכיות במתי״א רג״ב.

המוצר מממש תהליך עבודה שנתי בשלושה שלבים: תכנון, הערכה מעצבת והערכה מסכמת. הליבה המקצועית נשענת על מסמך העבודה והשאלון שגובשו עם הנהלת מתי״א רג״ב והפיקוח; שכבת ה־UX נועדה להפוך את אותו תוכן לכלי עבודה נוח, מדיד ורפלקטיבי — בלי לשנות את סמכות המסמך.

## מה ממומש

- שלושה חלונות גאנט: תכנון (יולי–ספטמבר), הערכה מעצבת (דצמבר–פברואר), הערכה מסכמת (מאי–יוני).
- חודשים שבין החלונות אינם מנוחשים — המערכת מבקשת לבחור שלב.
- מעבר לשלב 2 מחייב **תוכנית עבודה שמורה** עם קהל יעד, שינוי רצוי, שני מדדים ומסגרת זמן.
- ה־SMART נבחן ברמת התוכנית השלמה: קהל יעד, שינוי רצוי, שני מדדים ומסגרת זמן. שדה המטרה עצמו נדרש לנסח את השינוי הרצוי ואינו צריך לשכפל מדדים או זמן שנאספים בשדות הייעודיים.
- מעבר לשלב 3 מחייב לפחות התחלה של ההערכה המעצבת.
- מסלול ממוקד: סעיפים 1, 2, 5, 8, 9. מסלול מלא: כל תשעת הסעיפים.
- כל תתי־המדדים של השאלון נשמרים כשדות נפרדים: דירוגי 1–5 ו־1–10, אחוזים, מפגשים, תצפיות, תלמידים, שעות שטח, מנהלים, משאבים, תרבות, עצמאות ועוד.
- חישובי אחוזים מתוך הנתונים: תלמידי מוקד שהשתפרו, מימוש שעות שטח, פגישות מנהלים וממוצע אפקטיביות.
- חמשת ממדי המראה המקצועית נשענים על נתונים וראיות שנאספו; כאשר חסרה ראיה, הממשק מציין זאת במפורש.
- ניתוח formative כולל מגדלור חיובי, הזדמנות קריטית, סטטוס מדדים והמלצות קונקרטיות.
- היסטוריה מקומית של checkpoints מאפשרת לסגור לולאה מול הערכה קודמת.
- שלב 3 כולל הישג + מדד, נקודת מפנה, שינוי לשנה הבאה ו־rubric מותאם לפערים שנמדדו.
- שכבת ההקשר משתמשת באותות נצפים ובעלי עלות סיכון נמוכה כמו חלון השנה, חזרה אחרי הפסקה, סוג מכשיר ומשך סשן. היא אינה מנתחת את משמעות הטקסט החופשי לצורך התאמת UX.
- סוג המענה יכול לשמש להצגה רק ברמת המבנה שלו — למשל האם מולאו שדות פתוחים או מובנים — בלי ניתוח רגשי, אישיותי או סמנטי של תוכן הרפלקציה.
- RTL מלא, Heebo, mobile responsive, labels גלויים, focus states ואזורי לחיצה נוחים.

## עקרונות מוצר

1. **המסמך המקצועי הוא מקור האמת.** UX יכול לשנות דרך הצגה, לא משמעות מקצועית.
2. **ראיה לפני פרשנות.** ציון, אחוז או המלצה צריכים להיות ניתנים לעקיבה אל נתון שהמשתמשת הזינה.
3. **לא להמציא במקומות חסרים.** אם אין מספר או ראיה, מוצג "לא נמדד" או שחסרה ראיה; סתירה מקצועית שלא ניתן לפתור בלי שינוי סמכות נרשמת כ־`PENDING_HUMAN_AUTHORITY` במקום להיפתר בשקט.
4. **כישלון = חומר ללמידה.** פער בין יעד לתוצאה מוצג כהזדמנות לשינוי מנגנון, לא כביקורת אישית.
5. **בעלות ועצמאות.** המערכת בודקת מה נשאר בשטח גם ללא תלות גבוהה במדריכה.
6. **Representation Serves Practice.** לא מבקשים מהמשתמשת לייצג שוב מידע שכבר קיים בלי סיבה מקצועית נפרדת; ייצוגים נגזרים צריכים להחזיר ערך ולשמור על סמכות המקור.
7. **קוהרנטיות מערכתית.** קוד, מסמכים, UI, gates, פרטיות וסמכות חייבים לתאר אותה מערכת. זיהוי של auditor הוא ראיה לבדיקה, לא הרשאה לשנות תוכן מקצועי.

## פרטיות

בגרסת הפיילוט אין backend למסד נתונים ואין שליחה אוטומטית של תוכן רפלקטיבי למודל AI חיצוני או לשרת MATI. המידע המקצועי נשמר ב־`localStorage` בדפדפן המקומי וניתן למחיקה מהממשק. לכן אין סנכרון בין מכשירים ומחיקת נתוני האתר תמחק גם את היסטוריית העבודה המקומית.

קיימת אפשרות **מפורשת וידנית** לייצא קובץ signal ארגוני מסונן. הייצוא אינו שולח את הרפלקציה ואינו פעולה אוטומטית: הוא יוצר קובץ מקומי מתוך allow-list של מדדים מובנים בלבד. טקסט חופשי, שם מדריכה, שם מסגרת, טעויות ונקודות מפנה אינם חלק מחבילת ה־signal.

## ארכיטקטורה

```text
app/
├── layout.tsx                     # RTL, metadata, Heebo
├── page.tsx                       # professional flow and structured forms
├── experience-shell.tsx           # HOME / WORK / INSIGHT / JOURNEY
├── context-layer.tsx              # observable local context sensing
├── work-session-layer.tsx         # progressive disclosure by professional units
└── organizational-signal-*.tsx    # local projection transparency + explicit export

lib/
├── stages.ts                      # schema, stage gates, calculations and scoring
├── context-engine.ts              # deterministic observable-context strategy
├── organizational-signals.ts      # projection allow-list and systemic classification
├── ux-structural-contract.json    # field/fact/gate semantic contract
└── system-coherence-contract.json # representation + coherence invariants

scripts/
├── check-semantic-ux-contract.mjs
├── check-system-coherence.mjs
├── check-organizational-signal-contract.mjs
└── check-design-contract.mjs
```

## מה עדיין אינו ממומש במלואו

שכבת שיחה גנרטיבית מלאה — שאלות המשך חופשיות, פירוש עשיר של שפה טבעית והתאמת ניסוח בזמן אמת באמצעות LLM — אינה מופעלת עדיין. ההתאמה הנוכחית נשארת דטרמיניסטית ומקומית, כדי לשמור על פרטיות, עקיבות וסמכות לפני חיבור מודל חיצוני.
