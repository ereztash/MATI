# מתי המתי״א (MATI)

יישומון רפלקטיבי־מערכתי למדריכות חינוכיות, עם שלושה שלבים לאורך שנת העבודה:

1. **תכנון** — קהל יעד, מטרת SMART, מדדי הצלחה, מסגרת זמן וגמישות.
2. **הערכה מעצבת** — מסלול מלא או ממוקד, ניתוח 5 ממדים והמלצות קונקרטיות.
3. **הערכה מסכמת** — 3 שאלות ומחוון לשנה הבאה.

## פרטיות

הגרסה הנוכחית היא client-only. המידע נשמר ב-`localStorage` בדפדפן ואינו נשלח לשרת.

## פריסה

הפרויקט סטטי ומוכן לפריסה ישירה ב-Vercel ללא build step וללא משתני סביבה.
